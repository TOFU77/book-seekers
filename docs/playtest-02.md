# 検証記録 02 — 捜査から討論までの通し

実施: 2026-08-01 / `npm run fullcase`

持ち越しは**一座全体で5冊**に固定。捜査の采配を4種類に分けて150回ずつ通した。

## 測った采配

| 采配 | 中身 |
|---|---|
| 行き当たりばったり | 適当なペアを適当な場所へ |
| 証拠ばかり集める | 記録と現場にだけ行く。人には会わない |
| 人にばかり会う | 関係者と本人にだけ会う。記録を当たらない |
| **筋を通す** | 書物寄りと足寄りを組ませ、記録と人に一組ずつ。座談で急所が判明したらその主題の本を読む |

## 結果(抜粋)

**二つの失敗の仕方が、別々の形で現れている。**

- **証拠が足りない** → 定礎が組めず、勝率が落ちる(62〜89%)
- **相手を見ていない** → 勝てるが遅い(急所を外すので手数が1〜2手増える)

深い層ほど、どちらの怠りも致命的になる。層3では証拠ばかりが75%、人ばかりが62%、
筋を通して86%。

## 通し検証で発覚した設計の穴

初回の通しでは、**「人にばかり会う」采配が手帳タグを1個しか集めていないのに
勝率97〜100%だった。** 証拠の数がまったく意味を持っていなかった。

原因は単純で、**同じ証拠を何度突きつけても効き目が変わらない**実装だったこと。
領収書を8回見せても8回とも同じ威力があった。

**「手の内」の規則を足した** — 一度突きつけた証拠は二度目には驚かれない(減衰率0.6、
棚の慣れ0.3より厳しい)。証拠は本より一回性が強い。

これで「人にばかり会う」は62〜96%まで落ち、捜査で証拠を集める意味が生まれた。

**教訓: 資源に希少性が無ければ、それを集める行動に意味は生まれない。**
討論だけを見ていては気づけず、捜査と繋いで初めて見えた穴だった。

# 改訂02 — 手応えとして表明される揺らぎ

捜査に乱数を入れた。ただし**隠さず、本人の口から表明する**形にした。
揺らぎがあるぶん捜査日数を伸ばし、失敗を取り返す余地を作った(層1=4日 / 層2=5日 / 層3=6日)。

判定は当たり(0.20 + 踏み込み×0.10)／空振り(0.25 + 踏み込み×0.10 − 見守り×0.10)で、
当たりならタグ+1、空振りなら−1。軸3が危険度の性格になる。

## 日数の加減が難しかった

最初は層2を6日、層3を7日にした。結果、**全ての采配が100%・4.5手に揃い、
采配の差が消えた**。余裕を持たせすぎると、何をしても間に合ってしまう。

一日ずつ戻して層2=5日、層3=6日にしたところ、差が回復した。

## 残った課題

- 「証拠ばかり集める」でも層1は97〜100%勝てる。層1が浅いので当然だが、
  初心者に「人にも会うべき」と教える契機が弱い
- 場所の警戒(踏み込み3回で閉じる)が、現在の日数では滅多に発動しない。
  日数を削るか、警戒の閾値を下げるか
- 即席タグ(検索)を場所の産出物として置いているが、本来はいつでも引けるはず。
  「日数を使わずに引けるが、討論では読了者の同席が要る」という形にしたほうが
  検索・AI万能説へのアンチテーゼが立つ
