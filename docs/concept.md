# 企画コンセプト・ドキュメント

最終更新: 2026-08-01

## 動機

読書を通じて人文科学・自然科学の知識を幅広く得ているが、職業人としてそれを活かす場面が少ない。読書の楽しみを実利に結びつけることの是非とは別に、労働・職業が人間に求めるものが狭すぎるのではないか、という違和感が制作の出発点。

このゲームは、知識そのものを遊びの「動詞」にすることで、読書で得た知識に実利ではない形の出口を作ろうとする試み。

## ゲームの大枠

- ブラウザで動作する一人用RPG。
- 一回のプレイは数時間〜1週間程度で完結し、何度もやり直して遊ぶ前提(周回性)。長時間の一本道プレイではない。
- 少人数の固定キャストがいる。有名人・既存キャラクターをモチーフにしてよく、個性の違いへの感情移入を重視する。
- キャラクターは「変化しにくい属性」(役割原型・性格・関係性の力学)と「プレイヤーの関与で後天的に変動する属性」(知識・経験・道具)の二層を持つ。
- 登場人物同士の相互作用(化学反応)が起こる設計。

## 世界観・キャスト

- 幼馴染5人が中心キャスト。京極堂シリーズの役割原型(知識/記録/行動/取材/直感)のみを借り、キャラクター自体は写さない(著作権への配慮)。具体的な造形は後述「幼馴染5人」を参照。
- 拠点は古書店「柊書房」。幼馴染はここに定期的に集まり、知識や経験を交流させる。

## 時代設定: 現代・衰退した地方都市

2020年代の、緩やかに衰退していく地方都市。SNS・スマートフォン・生成AIが存在することを前提とする(2026-08-01確定)。戦後十年・大正も検討したが、以下の理由で現代を採った。

**1. 「知識が余る」という痛みは現代にしか存在しない**
1950年や1920年に本を持っている人間は端的に強く、知識は希少財だった。「読書で知識を得ているのに活かす場がない」という制作動機の違和感は、情報が安く豊富になった後にしか生まれない苦痛である。過去に設定すると企画の出発点にある感情そのものが成立しない。

**2. 検索と生成AIは「奥の棚」だけは出せない**
SNSとスマートフォンは問題ではなくエンジンに転用する。検索と言語モデルが出せないものが、奥の棚の三つに対応する:
- **編集の棚** — どういう文脈でその情報が並べられたか、何が省かれたか
- **来歴の棚** — その考えがどこから来て、何を前提にしているか
- **沈黙の棚** — そもそも書かれなかったこと

犯人は「調べればわかること」で武装している。それを崩すには調べても出てこないものが要る。**奥の棚が単なる解放条件ではなく主題の表明になる。**

**3. 京極堂シリーズと同時代を避ける**
著作権への配慮の観点から、戦後十年に置くと直接比較を招く。現代に移すことで距離が取れる。

### 検索・生成AIの扱い(確定・2026-08-01)

**このゲームは検索・AI万能説へのアンチテーゼとして設計する。** 検索と生成AIを禁止するのではなく、ゲーム内に組み込んだうえで「それだけでは足りない」ことを機構で示す。

| 場面 | 検索の扱い |
|---|---|
| **捜査フェーズ** | 検索で得たものは**即席タグ**として手帳に入る。安価・即時。その場のインスタントな進行には使える |
| **討論フェーズ** | 即席タグは**単独では機能しない**。定礎(書架の一冊 × 手帳の一葉)を作れないため |
| **討論中の検索** | 発動には**チームの呼吸**が要る。その分野の棚を読了している幼馴染が同席していなければ、即席タグを見識に変換できない |

**核心**: 検索結果は、読んだ人間が居て初めて意味を持つ。情報は誰でも引けるが、見識に変えるには読了と同席が要る。この非対称が、そのまま制作動機(読書が実利に結びつかないという違和感)への応答になる。

### 現代設定から得られる設計上の効果

- **深掘り分岐に倫理的な重みが生まれる**: 暴けばSNSで拡散し、誰かの人生が実際に終わる。収めれば不正は続く。軸4(暴く⇄収める)が好みの問題ではなく賭けになる。
- **5人全員が緩やかに沈んでいく職業**: 斜陽の古書店、在宅の外部校正者、後継者難の町工場、地方金融の苦境にある信用金庫、証明写真で食いつなぐ写真館。派手な貧困ではなく緩やかな衰退の陰が、そのまま「希望が持てない」空気になる。
- **噂の発生源としてのSNS**: 事件の発端モジュールとして使える。また拡散までの時間制限を作れる。

## ジャンル的な立ち位置

- 題材は殺人ではなく身近なスキャンダル(例: 教師の備品私的流用、部長の取引先リベート)。著作権への配慮と、モジュール化(量産)のしやすさの両面から、殺人ミステリーの緻密さを避けた。
- ジャンル的には日本の「日常の謎」(米澤穂信『氷菓』『小市民』シリーズ等)に近い。京極堂シリーズからは「憑物落とし」の構造だけを抽出し、日常の謎の題材に接木する組み合わせ。
- スキャンダル化により、知識タグは民俗学・宗教史のような特殊知識に偏らず、心理学(モラル・ライセンシング等)・組織社会学(逸脱の常態化)・経済学(プリンシパル・エージェント問題)・会計/統計的読み方など、人文科学と実務寄りの知識の両方が使えるようになった。当初の「人文科学および自然科学の知識を活かしたい」という動機に対して守備範囲が広がっている。

## コアループ

1プレイ = 1事件(入れ子状に深掘り可能)。

1. **発端**: サロンに事件の噂・依頼が持ち込まれる。
2. **分業捜査フェーズ**: プレイヤーは誰と誰をペアにしてどこへ派遣するか選ぶ。ペアの組み合わせ次第で得られる情報の質が変わる(化学反応)。
3. **収束フェーズ**: 論理の壁・心理の壁の両方に十分な材料が揃うと最終問答へ。
4. **最終問答(憑物落とし)**: 対峙する相手に対し、蓄積した知識・経験・証拠・道具の「タグ」を編成・シナジーさせて二重の壁を崩す。
   - **論理の壁(アリバイ・事実関係)**: 現場調査・証言収集など、行動的な捜査で崩れていく。証拠・証言タグの組み合わせで攻略。
   - **心理の壁(自己正当化)**: 幼馴染が持ち帰った知識の断片をサロンでの座談で突き合わせることで見えてくる。知識・経験タグの組み合わせで攻略。
5. **深掘り分岐**: 層を解決すると、幼馴染の誰かが「まだ何か隠れている」、別の誰かが「ここで止めよう」と主張する。プレイヤーはどちらの言い分を採るか選び、深掘りするかを決める。
   - 層が深まるごとに対峙する相手(自己正当化の持ち主)が変わる(末端→黙認していた管理職→制度を庇う上層部)。
   - 各層はそれ自体で起承転結を持つ独立した小事件として成立し、そこで打ち切っても遊びとして完結する。
   - 規模と時間のマッピング(たたき台): 層1=個人の私物化(数時間、タグ要求は少数) / 層2=部署ぐるみ(半日〜数日、複数幼馴染の専門知識の組み合わせが必要) / 層3=組織的隠蔽(数日〜一週間、幼馴染間の対立が先鋭化)。

# 捜査フェーズ

## 捜査が生むべきもの

模擬対局で判明した事実がこの設計を決めている——**討論の最中に相手を学ぶ時間は無い**。
よって捜査は証拠を集めるだけの作業ではない。**相手の反応トリガー(討論での急所)を、
ここで掴んでおかなければならない。**

捜査は、限られた日数を四つのものが奪い合う構造になる。

| 得るもの | 使い道 |
|---|---|
| **手帳タグ** | 定礎の材料。無いと討論が始まらない |
| **人物の理解** | 座談で反応トリガーに変わる |
| **読了** | 店に残った者が積読を崩す |
| (相手の警戒) | 踏み込みすぎると、その場所が口を閉ざす |

## 一日の流れ

各日、**2組のペアを派遣し、1人が店に残って本を読む**(5人なので過不足なく埋まる)。
夜、サロンで**座談**を開き、その日持ち帰ったものを突き合わせる。

**反応トリガーは座談でしか判明しない。** 人物の理解が一定量たまるごとに一つずつ見えてくる。
「捜査 → 座談 → 問答」という三段構えに、機構上の必然性がある。

## 気質四軸が、ここで全部仕事をする

| 軸 | 捜査での働き |
|---|---|
| 1. 書物⇄足 | **異極のペアだけ**が、本と領収書の両方を持ち帰る(手帳タグが1つ増える) |
| 2. 理屈⇄気配 | 気配寄りが同行すると、人物の理解が進む |
| 3. 踏み込み⇄見守り | 踏み込みは早く引き出すが、その場所の警戒を上げる。3回で口を閉ざす |
| 4. 暴く⇄収める | 討論の後、深掘り分岐で効く |

ペアの化学反応もそのまま効く。**反発ペアは網が広く**(タグが1つ増える)、
**共鳴ペアは深い**(タグの確度が1上がる)。

## 手応えとして表明される揺らぎ

捜査は思いどおりには進まない。一組の派遣ごとに**当たり／並／空振り**が判定され、
持ち帰るタグが増減する。

**ただし揺らぎは必ず本人の口から表明される。**

> 「手応えがある」／「まあ、こんなところだろう」／「今日は空振りだ」

さらに先の見通しも本人が言う。「まだ何か出そうだ」「これ以上は、物は出ない。人を見るだけだ」
「もう相手にしてもらえないだろうな」——もう一度そこへ行くべきかの判断材料になる。

**運を隠さないことが要である。** 揺らぎが表明されるからこそ、プレイヤーは
「編成が悪かったのか、運が悪かったのか」を切り分けられる。隠された乱数は
学習を妨げるが、表明された乱数は物語になる。

軸3(踏み込み⇄見守り)はここで**危険度の性格**になる。踏み込みは速いが当たり外れが大きく、
見守りは空振りが少ない。速さと安定のどちらを取るかという選択が生まれる。

揺らぎがあるぶん、**捜査日数には失敗を取り返す余裕を持たせてある**(層1=4日 / 層2=5日 / 層3=6日)。

## 出向く先

各層は3〜5の場所を持つ。記録の出る場所(帳場・書庫)、人の出る場所(関係者)、
現場、そして本人。**本人に会うとタグは出ないが、人物の理解が最も進む。**

## 証拠は一度きり

**一度突きつけた証拠は、二度目には驚かれない。** 討論で同じ手帳タグを繰り返すと
効き目が急速に落ちる(棚の慣れより厳しい)。

この規則が無いと、証拠を一つしか持たずに討論へ行っても勝ててしまい、
捜査で証拠を集める意味が消える。通し検証で実際にそうなり、後から足した規則である。

## 最終問答の実装方式: タグ編成・シナジー型

- Expedition 33のコンボ的発想に近い、デッキ構築的なシステム。捜査フェーズで集めたタグ(知識・経験・証拠・道具)を事前に編成し、問答中に組み合わせて壁を崩す。
- Ace Attorney的な対話選択肢型、犯人との削り合いゲージ型は不採用として検討済み。

# タグ体系: 書架

タグの分類体系は、抽象的なリストではなく**書店の棚割りそのもの**として表現する。プレイヤーの手札一覧が「店の棚」として見える。

## 二つの置き場

| 置き場 | 中身 | 永続性 |
|---|---|---|
| **書架** | 知識タグ(一冊＝一つの概念) | 店の資産として周回を跨いで残る |
| **手帳** | 証言・証拠・道具タグ | 各キャラが捜査で持ち帰る。事件ごとにリセット |

**核心規則: 壁は「書架の一冊 × 手帳の一葉」でしか崩れない。** 知識だけでも証拠だけでも崩れない。「この領収書の日付は、あの本に書いてあった祭礼の日だ」という接続が起きて初めて一撃になる。これにより捜査フェーズと問答フェーズが構造的に分離しない。

## 棚割り(14棚・4区分)

| 区分 | 棚 | 領域 | 蔵書の例 |
|---|---|---|---|
| **I 人を読む** | 人心の棚 | 心理学・精神医学 | モラル・ライセンシング、認知的不協和、防衛機制、認知の歪み(ベック)、発達段階(エリクソン) |
| | 世間の棚 | 社会学・組織論 | 逸脱の常態化、内集団びいき、儀礼的無関心、役割演技、組織的防衛ルーティン(アージリス)、支援関係(シャイン)、システム思考(センゲ) |
| | 土地の棚 | 民俗学・地方史・地理 | 贈答の作法、旧町名、祭礼暦、家制度、講と組 |
| | 物語の棚 | 文学・修辞・ナラティヴ心理学 | 悲劇の型、告白の文体、言い訳の類型、比喩の系譜、社会構成主義 |
| | 趣味の棚 | 美学・意匠・映画・芸能 | 認知詩学、身体性認知、意匠の流行、大衆芸能の型 |
| **II 世界を測る** | 数字の棚 | 統計・確率 | ベンフォードの法則、標本の偏り、相関と因果、生存者バイアス、実験計画法(フィッシャー) |
| | 物証の棚 | 化学・物理・生物 | インクの経年、音の伝播距離、植物の花期、腐敗速度 |
| | 技芸の棚 | 技術・実務・生活知 | 印刷と製本、鉄道時刻、写真の現像、園芸、料理 |
| **III 仕組みを解く** | 勘定の棚 | 経済・会計・監査 | プリンシパル・エージェント問題、サンクコスト、簿記の型、粉飾の手口、リスク研究、意思決定理論 |
| | 理法の棚 | 法学・制度・行政 | 規程の解釈、時効、内部通報、稟議の流れ、法哲学、規範倫理学 |
| | 言葉の棚 | 言語学・記号論 | 敬語の距離、婉曲表現、方言、命名と改名、認知言語学 |
| **IV 奥の棚**(店主の私架・層2以降で解放) | 編集の棚 | 編集工学・メディア論・出版史・書誌学 | 主語の後退、文脈操作、検閲史、版と刷、読者層の形成 |
| | 来歴の棚 | 科学史・科学哲学 | パラダイム論(クーン)、反証可能性(ポパー)、思惟経済(マッハ)、環世界(ユクスキュル)、疑似科学と科学メタファーの区別 |
| | 沈黙の棚 | 語られぬこと・余白・間 | 否定神学、間(ま)の研究、沈黙の合意、未定義の領域 |

**奥の棚の設計意図**: 区分I〜IIIが対象を扱う知であるのに対し、区分IVは**知そのものを扱うメタな知**。層1(個人の私物化)は表の棚で解けるが、層3(組織的隠蔽)は奥の棚を開けないと崩せない。奥の棚は棚またぎシナジーの威力が最大になるため、深い層ほど読書量が効いてくる。

## 蔵書・読了・積読

書架に「ある」ことと、キャラが「読んでいる」ことを分ける。

- **蔵書**: 店の棚にある＝使用可能な候補(周回を跨いで残る＝店の資産)
- **読了**: そのキャラが実際に切れる札(部分持ち越し＝キャラの素養)
- **積読**: 棚にあるが誰も読んでいない。事件の最中に読み込める(時間を消費する)

キャラの後天的属性＝読了状態、という対応がそのまま成立する。積読が実際にゲーム上の資源になる点は、この企画の動機から見て要となる。

## 将来の構想: 書物名をもう一枚被せる

現在、書架の一冊は**概念そのもの**である(「モラル・ライセンシング」「主語の後退」)。
最終的にはその上に**実際の書物名の層**を被せたい。

- 書物名は概念より数倍多い。一冊の本が複数の概念に触れ、複数の本が同じ概念に触れる
- **書物と主題の結びつきは自明ではない。** どの本がどの主題を担っているかは、
  読んでみるまで分からない — これが読書という行為そのものの模倣になる
- 読了済みの書物と主題が重なるものには色を付けて暗示するなど、
  プレイヤーが「この本とあの本は同じことを言っている」と気づく手がかりを与える

現在の実装は概念層だけで完結しているので、書物名層は上に足す形で導入できる。
無料版は概念層のみ、有料版で書物名層とシナリオ生成、という切り分けも考えられる。

## シナジー三種

1. **精読**(同じ棚の隣り合う二冊) — 深く刺さるが、重ねるほど逓減する
2. **棚またぎ**(異なる区分の組み合わせ) — 「意外な照射角」。区分が遠いほど威力が大きいが、成立条件が厳しい
3. **定礎**(書架 × 手帳) — 上記いずれにも必須の土台

幼馴染の同席・発言が技として発現する(誰を捜査に同行させたかがタグ入手経路として直接効く)。

## 【物語の棚】の特権

犯人の自己正当化は、それ自体が一つの**物語**である。よって文学の棚だけは特別扱いとし、**相手の語りの筋書きに名前を与える**ことができる唯一の棚とする。「あなたが今語ったのは、こういう型の話です」と指摘することが憑物落としのフィニッシャーになる。読書がそのまま最終手段になる構造。

# キャラクター設計

## 二層構造

`OLC-salon-prompt22.txt` の啓蒙徳目12種(節度・誠実・勇気・思慮・寛容・信義・感受・慰撫・探究・創意・静謐・気品)は**不採用**とした(2026-08-01)。18世紀サロンの女主人の規範項目に偏っており、閉じたリストから選ぶ形式のため人物の輪郭が立たない。

代わりに `OLC-cinema-prompt01.txt` の記法を採る。こちらの徳目は自由記述の3語(「突破力/実効性/動的平衡」「老獪/記憶/存続」「生活/現実直視/情の深さ」)で、規範ではなくその人の癖になっている。

ただし自由記述の語ではゲームが計算できない(ペアの化学反応・棚適性・深掘りの是非を判定できない)。よって二層構造とする:

- **下層 = 気質四軸**(このゲーム専用に新規作成・閉じた軸・機構を駆動する)
- **上層 = 人物票**(映画プロンプトの記法を踏襲・自由記述・描写を担う)

## 下層: 気質四軸

善悪ではなく、どちらの極も遊べる振れ幅として定義する。記法は ◎=強く寄る / ○=寄る / －=中庸。

| 軸 | 極A | 極B | ゲーム上の機能 |
|---|---|---|---|
| 1. どこから知を得るか | **書物** | **足** | 書架を読み進めるか、手帳を埋めるか |
| 2. どう理解するか | **理屈** | **気配** | 論理の壁に効く材料か、心理の壁に効く材料か |
| 3. 人にどう接するか | **踏み込み** | **見守り** | 早く吐かせるが警戒される／遅いが深く開く |
| 4. 決着に何を望むか | **暴く** | **収める** | 深掘り分岐でどちらを主張するか |

### ペアの化学反応の規則

- **同極ペア＝共鳴**: 深いが狭い。一つの筋を掘り下げた濃い情報が返る。
- **異極ペア＝反発**: 浅いが広い。噛み合わないぶん、拾う網が広くなる。
- **軸1で異極のペア(書物 × 足)だけが「定礎」の材料を持ち帰る**。一人が本を、一人が領収書を持ち帰るから突き合わせられる。核心のシナジー規則がそのままペア編成の意味になる。

## 反応トリガーの二重の役割

`OLC-salon-prompt22.txt` の規則「反応トリガーに触れた場合、通常の理性的な徳目を保留して自分の情動で発言を行う」を、二方向に流用する。

1. **犯人に対して** — 反応トリガーは**自己正当化が崩れる条件の定義そのもの**。犯人ごとに3つ書けば、心理の壁の攻略条件が定義できる。
2. **幼馴染に対して** — 捜査中にトリガーに触れると幼馴染が**勝手に動く**。予定外の情報を掴んでくるか、相手を怒らせて扉を閉じるか。プレイヤーが完全には制御できない仲間になり、「相互化学反応」が演出でなく機構になる。

## 配置の設計意図

**棚の分担**: 5人で14棚を覆う(得意3×5人＝15枠、人心のみ重複)。人心のみ望月と朝倉で重複(共鳴ペアを作れるようにするため)。奥の棚3つは柊(編集・来歴)と望月(沈黙)に分散させ、深い層では必ずこの2人のどちらかが要る構造にした。

**深掘り分岐の政治**: 軸4(暴く⇄収める)の配置が、そのまま深掘り分岐の勢力図になる。

| 人物 | 立場 |
|---|---|
| 真壁 | 暴く◎ — 常に掘れと言う |
| 柊 | 暴く○ |
| 瀬能 | 収める○ — 町で生き続ける立場から止めようとする |
| 望月 | 収める◎ |
| **朝倉** | **中庸 — 事実上のキャスティングボート** |

朝倉が中庸であることで、深掘りするかどうかの分岐に緊張が生まれる。プレイヤーはどちらの言い分を採るかを選ぶが、朝倉がどちらに傾くかが場の空気を決める。

**主要なペア**:

- **柊 × 真壁** — 全軸ほぼ異極。反発ペアの典型。網は広く、定礎材料(書物×足)が揃う。噛み合わないが最も生産的。
- **望月 × 朝倉** — 気配・見守りで同極。共鳴ペア。心理の壁の材料が深く手に入る。
- **瀬能 × 真壁** — 足・暴くで同極。共鳴だが、二人とも踏み込むため相手の警戒を招きやすい(暴走リスク)。
- **柊 × 望月** — 書物側で同極。書架は進むが手帳が埋まらない。知識偏重の失敗パターン。

## 周回間の持ち越し: 部分持ち越し + 上限つきの取捨選択

- 事件固有の証拠・道具タグは毎回リセットされる。
- 幼馴染個人の「素養」的な知識タグ(読了)はキャラクターの長期成長として周回を跨いで残る。
- 決め手: 一期一会の軽さ(スキャンダルはその都度使い捨て)と、何度もやり直す楽しみ(キャラクターが育っていく手応え)の両立。

### 持ち越しには上限をかける(2026-08-01確定)

**一度のプレイでどんなに多く読んでも、次のプレイに持ち越せるのは一座全体でN冊まで。**
周回のはじめに、プレイヤーが何を持ち越すかを取捨選択する。

- **一人あたりN冊ではなく、一座全体でN冊**。5人×3冊＝15冊では制約にならない。
  「三人に一冊ずつ」「誰か一人に三冊」といった薄さで初めて効く。
- 目安は全体で3〜6冊。検証では全体6冊のとき、選び方次第で勝率が48%〜100%に振れた。

**この仕組みは主題そのものを語っている。** どれだけ読んでも、次の場に持って行けるのは
わずかしかない — これは制作動機にある「職業や労働が人間に求めるものの狭さ」を、
そのまま遊びの規則にしたものである。

### 周回の手応えは、勝率ではなく手数の短縮に現れる

蔵書が育つと勝率は早々に頭打ちになる(100%に貼りつく)。周回を重ねた実感は、
**同じ事件が8手かかっていたのが5手で終わるようになる**ことのほうに現れる。
UIでは手数の記録を残し、前回との比較を見せる。
