# 検証記録 01 — 手書き事件5本の模擬対局

実施: 2026-08-01 / `npm run simulate`

> **改訂02(同日)**: 何も考えないプレイヤーに勝ち筋が無かった問題と、
> 周回で難易度が落ちる問題を調整した。最新の数値は末尾「改訂02」を参照。
> 本文前半の数値は改訂前のもので、調整の経緯として残してある。

手書きの事件5本を、技量の違う5種類のプレイヤーに200回ずつ解かせ、
「何手で解けるか」「どの技量で失敗するか」を測った。

## 測ったプレイヤー

| 技量 | 中身 |
|---|---|
| 手当たり次第 | 適当な手帳と適当な1〜3冊を、適当な壁に投げる |
| 素直 | いちばん威力の高い本を単品で出す。組み合わせを考えない |
| 主題を読む | 全組み合わせを探索して最善手を選ぶ。ただし**相手のことは何も知らない** |
| 手探りから学ぶ | 上に加えて、打った結果から相手の急所と耐性を推測して修正する |
| 完全情報 | 相手の弱点主題も耐性棚も全て知っている。理論上の上限 |

「主題を読む」と「完全情報」の差が、**相手を読むことの価値**にあたる。

| 祭りの積立 | 0% | 1% | 98% / 4.8手 | 99% / 4.8手 | 100% / 3.8手 |

| 信用の担保 | 1% | 1% | 99% / 4.5手 | 100% / 4.6手 | 100% / 3.5手 |

### 層2(手数8)・層3(手数10)

| 事件・層 | 主題を読む | 完全情報 |
|---|---|---|
| 歳暮 層2 | 95% / 5.8手 | 100% / 4.2手 |
| 積立 層2 | 98% / 5.7手 | 100% / 4.1手 |

**層1が平均4.7手・手数6。「5回試せば解ける」にほぼ一致している。**

## 調整の過程で分かったこと

### 1. 回数制限がなければ、どんな数値でも必ず解ける

初期実装には手数の制限が無かった。この状態では％をどう調整しても失敗が存在しない。
**難易度を作るのは倍率ではなく手数である。** 現実の追及にも無限の時間はない。

### 2. 最初の版では「相手を読むこと」が無意味だった

初回の測定で、相手を何も知らないプレイヤー(4.3手)と全て知っているプレイヤー(4.0手)の差が
0.3手しかなかった。**棚の組み合わせを解くだけのパズルになっており、
相手が誰であるかがほとんど関係していなかった。** ミステリーとして失格である。

原因は、適合倍率(相手の読み・1.3倍)が結合倍率(棚の遠さ・最大1.8倍)より小さかったこと。
重心を逆転させた(適合1.9倍 / 結合最大1.6倍)。

**教訓: 棚の遠さより、相手の読みのほうが大きく効かなければならない。**

### 3. 主題の分布が偏っていると、狙わずに当たってしまう

初期の蔵書28冊では、記録と忘却が8冊・沈黙と告白が9冊ある一方、
交換と贈与と過剰と欠乏は2冊しかなかった。common な主題は偶然当たるため、
相手の急所を狙う意味が薄れる。分布を均した(現在 3〜7冊)。

### 4. 「撒けば当たる」を潰す必要があった

適合倍率を上げた直後、**手当たり次第のプレイヤーが45〜60%勝つ**ようになった。
3冊撒けば主題が6つ乗るので、2つの弱点主題のどちらかに偶然当たってしまうためである。

二つの規則で塞いだ。

- **通り一遍**: 急所を外し、かつ組み合わせも成っていない論述は半減する
- **筋の主題だけが急所に当たる**: 判定に使うのは、複数冊なら全冊の共有主題、単品ならその一冊の主題

結果、手当たり次第は0〜1%、素直も0〜1%に落ちた。技量の下限ができた。

この二つ目の規則には副産物がある。**一冊でも相手の急所に当たれば、それは効く。**
何冊積んでも筋が通っていなければ動かない。読書の手応えとして正しい方向だと思う。

## 設計上の発見

### A. 討論中に学習しても間に合わない

「手探りから学ぶ」プレイヤーは、「主題を読む」プレイヤーとほぼ同成績だった(4.7手 対 4.7手)。
5〜6手の討論では、相手を観察して学び、それを活かす時間が無い。

一方で「完全情報」は1手速い(3.7手)。**情報には価値があるが、討論中には手に入らない。**

これは企画の構造を裏づけている。**相手の反応トリガーは、討論ではなく捜査フェーズで
掴んでおくべきものである。** 捜査で人物を調べ、サロンの座談で像を結び、
その上で問答に臨む — という三段構えに機構上の必然性が生まれた。

捜査フェーズを実装するとき、「相手の反応トリガーを一つ掴む」を
明確な成果物のひとつにする。

### B. 層3は奥の棚がなければ本当に崩せない

層3(信用の担保・堅さ100・表の棚に耐性)に、同席者を変えて挑ませた。

| 同席者 | 主題を読む | 手探りから学ぶ | 完全情報 |
|---|---|---|---|
| 柊・望月を含まない(奥の棚の読了者なし) | 25% | 22% | 86% |
| 柊・望月を含む | 91% | 94% | 100% |

**誰を同席させるかが勝敗を決めている。** 奥の棚を読める者が居ないと、
理論上の最善を尽くしても人間の技量では届かない。設計意図どおりに動いている。

### C. 蔵書が育つと事件は解けるようになる(周回の手応え)

各人の読了冊数を変えて層1を解かせた。技量は「手探りから学ぶ」で固定。

| 読了 | 石膏像 | 歳暮 | 積立 | 広報 | 信用 |
|---|---|---|---|---|---|
| 2冊 | 57% / 5.4手 | 63% / 5.5手 | 49% / 5.2手 | 60% / 5.2手 | 62% / 5.2手 |
| 3冊 | 86% / 5.2手 | 93% / 5.4手 | 81% / 5.3手 | 91% / 5.0手 | 90% / 4.9手 |
| 4冊 | 94% / 4.8手 | 98% / 5.1手 | 92% / 5.0手 | 98% / 4.7手 | 97% / 4.7手 |
| 5冊 | 99% / 4.8手 | 99% / 4.9手 | 98% / 4.9手 | 100% / 4.5手 | 100% / 4.5手 |
| 6冊 | 99% / 4.6手 | 100% / 5.0手 | 100% / 4.8手 | 100% / 4.5手 | 100% / 4.4手 |

**「部分持ち越し」の設計が機能している。** 一周目(各人2〜3冊)では半分近く失敗し、
読了が進むと確実に解けるようになる。手数はさほど変わらず、変わるのは**成功率**である。
これは「知識が増えると、解けなかったものが解けるようになる」という手応えそのものである。

### D. 事件ごとの難易度差は、蔵書が薄いときにだけ現れる

5本の事件の難易度差は、読了5〜6冊では 4.4〜5.0手 とほとんど差がない。
一方、読了2冊では 49%〜63% と14ポイントの差が出る(最難は祭りの積立)。

**蔵書が育つほど、事件の個性は平準化する。** 手札が厚くなると、
どんな相手にも何かしら良い組み合わせが見つかってしまうためである。

対策は難易度を上げることではなく、**層を深くすること**である。
入れ子構造がそのまま後半の手応えを担保する設計になっている。

# 改訂02 — 何も考えないプレイヤーへの配慮と、持ち越し上限

改訂01の課題のうち、「素直なプレイヤーの勝率が0〜1%では厳しすぎる」に対処した。
**何も考えずに遊びたいプレイヤーにも2割ほどの勝ちを残す**ことを目標にした。

## 変えたこと

### 1. 適合を三段階に分けた

| 種別 | 倍率 | 条件 |
|---|---|---|
| 筋が通った | ×2.2 | 複数冊の**共有主題**が急所を突く |
| かすった | ×1.7 | **単品**で、その一冊の主題が急所に触れる |
| 通り一遍 | ×0.65 | かすりもせず、組み合わせも成っていない |

### 2. 「かすった」は単品にだけ認めた ← 決定的だった

最初は複数冊にも「かすった」を認めた。結果、**手当たり次第のプレイヤーが34〜51%勝ち、
素直なプレイヤーは0%**という逆転が起きた。3冊撒けば主題が6つ乗るので、
撒くほうが当たりやすかったためである。

単品限定にしたところ、手当たり次第は1〜5%に落ち、素直は上がった。

**教訓: 「偶然の当たり」を認める範囲を広げると、考えないプレイのほうが強くなる。**

### 3. 手数を増やした(6→8 / 8→10 / 10→12)

素直なプレイヤーは壁を崩すのに約10手を要する。手数6では構造的に勝てない。
組み立てるプレイヤーの5手はそのままに、手数を8にすることで
素直なプレイヤーに勝ち筋が生まれた。

## 改訂02の結果(層1・手数8)

| 事件 | 手当たり次第 | 素直 | 主題を読む | 手探りから学ぶ | 完全情報 |
|---|---|---|---|---|---|
| 消えた石膏像 | 3% | **21%** / 7.6手 | 100% / 4.7手 | 100% / 4.7手 | 100% / 3.4手 |
| 歳暮の行方 | 2% | 4% / 8.0手 | 100% / 5.0手 | 100% / 4.9手 | 100% / 3.3手 |
| 祭りの積立 | 2% | **25%** / 7.8手 | 100% / 4.8手 | 100% / 4.7手 | 100% / 3.5手 |
| 広報の一枚 | 3% | **15%** / 7.5手 | 100% / 4.6手 | 100% / 4.5手 | 100% / 3.2手 |
| 信用の担保 | 5% | **20%** / 7.7手 | 100% / 4.4手 | 100% / 4.5手 | 100% / 3.1手 |

**素直なプレイヤーは7.5〜8.0手かけて約2割勝つ。組み立てるプレイヤーは5手で解く。**
乱雑なプレイは1〜5%に留まる。狙った釣り合いに収まった。

歳暮の行方だけ4%と低いのは、この事件の弱点主題「交換と贈与」が
蔵書中3冊しかない稀少な主題だからである。**稀少な主題を弱点に据えると事件が難しくなる**
という調整の手綱が、意図せず確認できた。

## 持ち越し上限の検証

周回で難易度が落ちる問題に対し、**持ち越せる知識タグに上限をかけ、
周回のはじめに取捨選択させる**案を検証した。

### 一人あたりではなく、一座全体でN冊

当初は一人あたりN冊で試したが、**5人×3冊＝15冊では制約にならず**、
勝率は96〜100%のまま動かなかった。一座全体でN冊に改めたところ、はっきり効いた。

各事件の**最深層**で測定(技量は「手探りから学ぶ」で固定)。

| 持ち越し | 石膏像 層1 | 歳暮 層2 | 積立 層2 | 広報 層2 | 信用 層3 |
|---|---|---|---|---|---|
| 潤沢(15冊相当) | 100% / 4.4手 | 100% / 5.6手 | 100% / 5.1手 | 100% / 5.0手 | 89% / 8.8手 |
| 全体9冊 | 100% / 4.9手 | 98% / 6.8手 | 99% / 6.4手 | 95% / 6.0手 | 68% / 9.3手 |
| 全体6冊・行き当たり | 98% / 5.4手 | 89% / 7.3手 | 80% / 7.5手 | 80% / 6.9手 | 41% / 9.1手 |
| **全体6冊・選べた** | 99% / 4.5手 | 99% / 5.8手 | 96% / 6.3手 | 100% / 4.9手 | **76%** / 8.8手 |
| **全体6冊・外した** | 95% / 6.3手 | 64% / 9.6手 | 70% / 9.1手 | 48% / 9.4手 | **5%** / 10.3手 |
| 全体3冊・行き当たり | 54% / 6.3手 | 39% / 7.7手 | 23% / 7.6手 | 31% / 6.3手 | 21% / 9.1手 |
| 全体3冊・選べた | 81% / 4.9手 | 69% / 7.3手 | 49% / 7.8手 | 73% / 6.5手 | 33% / 9.5手 |
| 全体3冊・外した | 55% / 7.1手 | 9% / 10.0手 | 8% / 9.9手 | 7% / 10.0手 | 0% |

**上限をかけると、ゲームの性質が「たくさん読む」から「何を選ぶか」に変わる。**
全体6冊のとき、広報層2で 選べた100% 対 外した48%、信用層3で 選べた76% 対 外した5%。
持ち越しの選択が、そのまま事件の成否になっている。

同時に**手数にも現れる**。広報層2では、選べたときは4.9手、外したときは9.4手。
**周回の手応えは勝率よりも「同じ事件が短い手数で終わるようになること」に現れる。**

### この仕組みが主題を語っている

どれだけ読んでも次の場に持って行けるのはわずかしかない、という制約は、
制作動機にある「職業や労働が人間に求めるものの狭さ」をそのまま遊びの規則にしたものである。
機構が主題を語る形になっている。

## 残った課題

- 事件の個性(祭りの積立で土地の棚が耐性になる等)は、蔵書が潤沢だと数値に現れない。
  持ち越し上限をかけると差が出る(全体6冊で 80%〜100%)ので、
  **上限の存在が事件の個性を守っている**とも言える
- 初見のプレイヤーが最初の1〜2手で何も削れずに終わる体験になりうる。教示の設計が要る
- 「かすった」倍率1.7は、単品連打がやや強い。実際に触ってみて調整する
- 持ち越し上限Nの具体値(3か6か)は、実際の周回体験を見てから決める
