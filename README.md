# 柊書房 -- Hiiragi Shobo

衰退していく地方都市の、潰れかけた古書店。
ここに集まる五人の幼馴染が、町に持ち込まれる小さな醜聞を解いていく、
ブラウザで遊ぶ一人用のミステリー RPG です。

武器は棚の本だけ。証拠を突きつけても、人は自分の物語を手放しません。
**離れた分野の本が同じことを言っていると気づいたときにだけ**、相手の言い分は崩れます。

読書で得た知識それ自体が、そのままゲームの手駒になる -- というのがこの企画の芯です。

## 遊んでみる

```bash
npm install
npm run dev
```

ビルドは `npm run build`（`dist/` に出力）。

GitHub Pages 用の設定は `github-workflows/` にあります（`base` 付きの `vite.config.ts` と
`deploy.yml`）。`main` への push で自動ビルド・自動デプロイされます。

## 遊び方のあらまし

1. **事件を選ぶ** -- タイトル画面。一層完結の事件から。3件解くと多層の事件が開きます。
2. **捜査** -- 五人を1〜2名の組に編成して聞き込みに出すか、店番に残して蔵書を読む。
   日数は限られています。捜査の合間には**座談**（掛け合い）が挟まります。
3. **問答** -- 手帳（証拠）を1つ、書架（知識）を1〜3冊選んで、相手の「論理の壁」
   「心理の壁」を崩す。同じ証拠は二度目には効きにくく、離れた棚の本が同じ主題を
   共有していると大きく効きます。
4. **エピローグ** -- 崩せたか、崩せなかったか。層が残っていれば、掘るか収めるかを
   幼馴染たちが言い争います。
5. **持ち越し** -- 読んだ本のうち5冊だけを、次の事件へ持ち越せます。

いつでも「諦める」で未解決のまま切り上げられます。タイトル画面の「履歴」で、
これまでの解決記録（回数・最新の手数・読んだ本）を確認できます。

## 仕組み

`engine/` はゲームのルールだけを持ち、`content/`（事件・人物・書物などのデータ）を
一切 import しません。データを差し替えれば別の事件セットでも同じルールで遊べる、
という分離を保っています。

```
src/
  types.ts          共通の語彙(棚・主題・書物・人物・壁・座談イベント...)
  engine/
    rng.ts          決定論的乱数(mulberry32)。同じ種は同じ揺らぎを再現する
    synergy.ts       論述の評価(単品/精読/棚またぎ/寄せ集め、適合倍率、証拠の減衰)
    debate.ts        問答フェーズの状態機械
    investigate.ts   捜査フェーズの状態機械。座談は SalonEvent という構造化イベントだけを返す
  content/
    shelves.ts / themes.ts   14棚・10主題の索引
    books/index.ts   蔵書58冊。実在の書物(千夜千冊由来の古典 + 各概念の定番書)
    cast.ts          幼馴染5人。気質四軸でペアの化学反応が決まる
    banter.ts         座談の掛け合い。engine の SalonEvent を受けて、誰が何の感情で
                       何と言うかを決める(engine → content の依存は発生しない)
    cases/           手書きの事件(全15本)
  ui/
    App.tsx          場面(タイトル/捜査/問答/エピローグ/持ち越し/履歴/エンディング)の遷移
    Investigation.tsx / scenes.tsx / styles.css
tools/
  tune.ts / simulate.ts / fullcase.ts   バランス検証(下記)
```

### 主な機構

- **壁は二重**: 論理の壁(アリバイ)と心理の壁(自己正当化)を、共通の手数で崩す。
- **定礎**: 手帳タグ1枚 + 書架1〜3冊の組み合わせでしか論述は成立しない。
- **三段の結合**: 精読(同じ棚を重ねる)・棚またぎ(離れた棚が主題を共有する、最も効く)・
  寄せ集め(ただの数合わせ、通り一遍)。
- **証拠の一発性**: 同じ手帳タグを使い回すほど、相手は驚かなくなる(`shown` の減衰)。
- **持ち越しの取捨選択**: 一座全体で5冊まで。周回するほど有利になりすぎないための蓋。
- **座談**: 捜査で急所・耐性が判明した日、あるいは手応えの良い日・空振りの日が
  2日続いた日にだけ、五人のうち二人が短い掛け合いを交わす。誰が話すかは気質からの
  重み付け抽選(決定論的乱数、同じ捜査は同じ掛け合いを再現する)。

## 検証ツール

```bash
npm run typecheck   # 型検査
npm run tune        # 論述の一手ごとのダメージ内訳を表示
npm run simulate    # 200回 x 5スキル帯 x 全事件層のシミュレーション
npm run fullcase    # 捜査→問答を通しで走らせ、采配方針ごとの勝率・手数を比較
```

## 出典について

蔵書のうち古典寄りのものは、松岡正剛「千夜千冊」を選書の手がかりにしています。
実在する書物への言及であり、ゲーム内の要約(`gist`)はその核心を一行に凝縮した
フィクション上の演出です。事件・人物はすべて架空で、実在の事件・人物とは無関係です。
